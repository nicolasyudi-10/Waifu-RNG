# Waifu RNG — layout lateral real

A interface foi mantida com a mesma lógica e funcionalidades, mas agora, em telas largas, o palco da carta ocupa a coluna principal e Loja/Coleção/Chances ficam claramente ao lado, em uma coluna lateral fixa.

Em telas menores, o layout empilha automaticamente para continuar utilizável.


### Atualização Low-Spec
A animação mantém a mesma sequência visual, mas usa menos camadas, menos partículas, sem shake global e com atualizações do roll visual mais espaçadas para PCs fracos.
